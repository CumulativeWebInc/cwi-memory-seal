Honest limits

  • Heuristic rules, not a proof: a clean scan does not mean clean memory.
  • Findings are triage input for a human — never automatic verdicts.
  • MS-01/MS-04 will fire on your own standing policy text. Mark those as POLICY.
  • Adversarial memory can evade rules. v1 flags for review; it does not certify.

Seal a memory checkpoint

A checkpoint seals a snapshot of memory entries with a SHA-256 hash chain and an Ed25519 signature. It proves the entries were not added to, removed, edited, or reordered since sealing — it says nothing about whether they were true when sealed.
